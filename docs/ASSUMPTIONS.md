# Assumptions

1. One effective tire thermal state is used; tread, carcass, gas, belt and surface temperatures are not separated.
2. Heat input is derived from telemetry proxies and is not a measured heat-flow signal.
3. The grip-temperature curve is assumed and parameterized.
4. Default parameters are illustrative placeholders and must be replaced or justified before publication.
5. The performance model is not a full nonlinear tire-force or multibody vehicle model.
6. Simulated tire temperature must never be described as measured Formula One tire temperature.
7. The project supports sensitivity analysis and model comparison, not proprietary tire reconstruction.
